## 已实现

- **学习路线**：首页 → 准备篇五页 → 个人主页案例 → Todo 备注案例 → 方法速查。两个案例统一为“想清楚、定计划、生成并运行、发现问题并修改、检查并交付”。
- **需求分析**：五问选择与补充、实时需求单、模糊与明确需求的对照、先要计划的提示词、复制与下载。草稿保存在浏览器；后续预设案例使用固定示例，并明确说明不会根据草稿实时生成代码。
- **个人主页闭环**：同一个 `my-homepage`、同一份 `index.html`；初稿在 375px 真实溢出，修复只改变样式。提示词、文件、终端、浏览器、真实 Diff 与交付物连成一条线。
- **已有项目闭环**：保留 React / Express / SQLite Todo 素材；先读结构、限定四个文件，再加入备注，复现“勾选完成丢备注”，解释未传入与传入空字符串的区别，最后做功能、回归和范围检查。
- **状态边界**：Agent 回复、文件保存、程序运行、结果验证分开显示；示例结果不自动勾选本机完成状态。网页不访问本机安装信息、不执行本机命令、不调用实时 AI。
- **界面**：中性色与蓝色强调、最小 12px、统一圆角；桌面窄说明栏与大场景、手机场景优先；支持暗色、抽屉键盘焦点、方向键小步导航、减少动效。删除旧七阶段工作台、重复流程页及旧样式。
