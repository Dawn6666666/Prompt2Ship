> 这份文档集是 Prompt2Ship 的整体重构指南，覆盖产品定位、信息架构、案例设计、工作台交互、视觉系统、文案和实施顺序。
> 现有代码、样式和文案都可以重写，判断标准只有一条：**一个大一下学期、第一次接触 Vibe Coding 的同学，能不能看懂、跟得上、做得出来。**

## 一句话定位

**带你从空文件夹到能交付的网页，看懂并亲手走通一次和 AI 一起写代码的完整过程。重点讲“想清楚要什么”。**

## 六个核心决定

1. **两个案例只讲五步，而不是七步。** 想清楚 → 定计划 → 生成并运行 → 发现问题并修改 → 检查并交付。七步对新手太碎，“验证修改”和“完成交付”本来就是同一件事。
2. **需求分析单独成为一个完整环节。** 现在它只是七个阶段之一加一段提示词。重构后它在案例一中占篇幅最大，有专门的“需求拆解器”交互，并在首页和速查页反复出现。
3. **全站只用一个项目名、一个人物、一套工具。** 人物是大一学生，项目文件夹统一叫 `my-homepage`，运行方式统一用 Node（`npx serve`），不再混用 Python。
4. **用四种颜色标出四种状态：Agent 回复了、文件保存了、程序跑起来了、结果验证过了。** 全站统一，读者一眼就能看出“AI 说做完了”和“真的做完了”不是一回事。
5. **工作台以“场景”为主体，说明退到旁边。** 桌面端左侧是窄说明栏，右侧是大面积仿 VS Code 场景；手机端先给场景，说明折叠在下方。
6. **去掉所有装饰性信息。** 包括全站流水编号“动态 07”、英文小标题（CASE STUDY / 01）、“7 个动态”这类元标签和重复出现的“预设案例”提示。最小字号 12px。
