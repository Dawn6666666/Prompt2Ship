# 08 · 视觉系统

目标气质：**安静、清楚、像一本做得好的教材**。少装饰、多留白；颜色只用于表达状态和可点击；界面看起来像工具而不是营销页。

## 一、字体

```css
--font-sans: "Inter", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "SF Mono", "Cascadia Code", Consolas, "Noto Sans Mono CJK SC", monospace;
```

- 中文正文不使用等宽字体；等宽字体只用于代码、命令、文件名、路径。
- 删除所有大写英文等宽 eyebrow（`CASE STUDY / 01` 等）。

## 二、字号（6 级，最小 12px）

| 令牌 | 尺寸 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--text-display` | clamp(32px, 5vw, 48px) / 1.2 | 600 | 仅首页 H1 |
| `--text-title` | 24px / 1.35 | 600 | 页面标题、步骤标题 |
| `--text-heading` | 18px / 1.45 | 600 | 区块标题、卡片标题 |
| `--text-body` | 16px / 1.75 | 400 | 正文、说明 |
| `--text-small` | 14px / 1.6 | 400 | 辅助说明、标签、按钮、代码 |
| `--text-caption` | 12px / 1.5 | 500 | 行号、状态标签、角标 |

- 代码块 14px（手机 13px），终端 14px。
- 仿 VS Code 场景内允许整体缩放，但缩放后实际渲染字号不低于 12px；做不到时改为可横向滚动而非缩小。
- 重构后用 lint 规则禁止样式中出现小于 12px 的 `font-size`。

## 三、颜色

### 3.1 中性色（亮色主题）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#FFFFFF` | 页面背景 |
| `--bg-subtle` | `#F7F7F5` | 场景外框、侧栏 |
| `--surface` | `#FFFFFF` | 卡片、窗口 |
| `--border` | `#E6E6E2` | 分隔线、边框 |
| `--text` | `#1C1C1A` | 正文 |
| `--text-muted` | `#6B6B66` | 辅助文字（对白底对比度 ≥ 4.5:1） |

暗色主题：`--bg #141414`、`--bg-subtle #1B1B1A`、`--surface #1F1F1E`、`--border #2E2E2C`、`--text #EDEDEA`、`--text-muted #A3A39E`。

中性色微带暖调，避免纯冷灰带来的“后台系统感”。

### 3.2 强调色

- `--accent: #2F5BEA`（保留现有蓝色方向，略降饱和），仅用于主按钮、链接、当前步骤、焦点环。
- 一个页面中强调色面积不超过一个主按钮 + 步骤条当前项。

### 3.3 状态色（全站唯一含义，不能挪作他用）

| 令牌 | 亮色 | 暗色 | 含义 |
|---|---|---|---|
| `--state-reply` | `#7C5CD6` | `#A08AF0` | Agent 回复了 |
| `--state-saved` | `#2F7BD9` | `#5EA0F0` | 文件保存了 |
| `--state-running` | `#1F9D6B` | `#3CC48D` | 程序跑起来了 |
| `--state-verified` | `#11734B` | `#5BD6A0` | 结果验证过了 |
| `--state-problem` | `#D14343` | `#F07171` | 问题 / 冲突 / 未通过 |
| `--state-planned` | `#C2780A` | `#E9A23B` | 将修改（案例二） |

- 每种状态色配一个 8% 透明度的背景色（`--state-*-bg`），用于高亮行和标签底色。
- `--state-saved` 与 `--accent` 都是蓝，需要用图标区分；如果测试中容易混淆，把 `--state-saved` 调为青色 `#1A8FA3`。

### 3.4 Diff 与代码

- 新增行：`--state-running-bg` + 左侧 2px 绿条；删除行：`--state-problem-bg` + 左侧 2px 红条。
- Shiki 主题：亮色 `github-light`，暗色 `github-dark-dimmed`，与仿 VS Code 窗口的背景一致。

## 四、间距、圆角、阴影

- 间距基于 4px：常用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96。
- 圆角只有两种：`--radius-sm: 6px`（按钮、输入、标签、代码块）、`--radius-lg: 12px`（场景窗口、卡片、抽屉）。圆形用 `9999px`。
- 阴影只有一种：`--shadow: 0 1px 2px rgb(0 0 0 / .04), 0 8px 24px rgb(0 0 0 / .06)`，只用于浮层（抽屉、下拉、弹出说明）和场景窗口。
- 卡片原则：**不嵌套**。场景窗口内部用分隔线分区，不再在窗口里放带边框的卡片；说明栏不用卡片，靠标题与留白分组。

## 五、版心与栅格

- 阅读类页面（准备篇、速查）：正文最大宽 680px；右侧可选 240px 的辅助栏。
- 案例页：最大宽 1440px，左栏 280px + 场景。
- 首页：单列 960px，演示区可放宽到 1120px。
- 页面左右留白：桌面 32px，手机 16px。

## 六、组件外观要点

| 组件 | 规范 |
|---|---|
| 主按钮 | 实心 `--accent`，白字，高 40px，14px 字，6px 圆角；全站每屏最多一个 |
| 次按钮 | 透明底 + `--border` 描边 |
| 文字按钮 | 无边框，`--text-muted`，悬停 `--text` |
| 步骤条 | 数字圆 24px + 名称；当前项 `--accent` 实心；完成项 ✓；连接线 1px |
| 标签 | 12px 字，`--state-*-bg` 底，`--state-*` 文字，6px 圆角，高 22px |
| 提示词块 | `--bg-subtle` 底，左侧 3px `--state-reply` 条（表示“发给 Agent 的话”），右上复制按钮 |
| 命令块 | 深色终端样式，`$` 前缀不可复制 |
| 需求单 | 纸张感：白底，行与行之间细分隔线，左侧显示问题编号 1–5；被引用行出现 `--accent` 左边条 |
| 仿 VS Code 窗口 | 只做必要的形似：标题栏（三点 + 文件夹名）、活动栏图标、标签页；不模拟菜单栏和状态栏细节 |

## 七、图标与插图

- 统一使用 Lucide 图标，线宽 1.75，尺寸 16 / 20。
- 不使用装饰性插图、渐变光斑、3D 元素。
- 真实截图统一处理：12px 圆角、1px 边框、不加阴影、宽度不超过版心；截图上的标注用 `--accent` 圆角矩形框 + 数字角标。

## 八、动效

- 只用于表达变化：出现（淡入 + 上移 4px，180ms）、高亮（背景淡入淡出 1.2s）、状态点亮（缩放 1→1.08→1，300ms）、连线（路径描绘 400ms）。
- 步骤切换：内容淡入 150ms，不做横向滑动。
- 缓动统一 `cubic-bezier(.2,.8,.2,1)`。
- `prefers-reduced-motion: reduce` 时只保留颜色变化。

## 九、首页视觉

- 不使用左右分栏 Hero。H1 + 一句副标题 + 主按钮，居左单列；下方紧跟演示区，演示区占据视觉重心。
- 演示区是工作台缩小版：真实组件、真实代码、真实预览，循环播放 20 秒情节，有暂停按钮。
- 页面背景纯色，无纹理、无渐变。
