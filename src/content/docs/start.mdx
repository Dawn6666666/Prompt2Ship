这份指南面向刚开始 Vibe Coding 的你：把想法说清楚，让 AI 帮你写代码，再亲自运行、检查和修改。

**AI 不是替你按下“完成”按钮的人。你来决定做什么，也由你确认做得对不对。**

## 你需要准备什么

| 工具           | 负责什么                   | 怎么知道它能用               |
| -------------- | -------------------------- | ---------------------------- |
| VS Code        | 看文件、编辑、打开终端     | 打开项目目录，能找到三个区域 |
| Node.js 与 npm | 启动本地网页、运行项目工具 | 命令输出版本号               |
| Git            | 记录能回看的代码版本       | 能初始化仓库并查看状态       |
| 一个编程 Agent | 读文件、提方案、修改代码   | 完成连接，响应一个只读请求   |

Agent 可以在集成终端里运行，也可以有自己的扩展面板。**不是每个 Agent 都需要安装 VS Code 插件。**

## 按顺序准备

<LearningProgress client:load />

1. [安装并认识 VS Code](/start/editor/)：找到文件区、编辑区和集成终端。
2. [准备运行与版本工具](/start/tools/)：安装 Node.js 和 Git，并检查输出。
3. [安装并连接 Agent](/start/agent/)：主线使用 OpenCode V2，你也可以用已经连接好的其他工具。
4. [开工检查](/start/check/)：创建 `my-homepage`，确认工具能一起工作。

已经全部配置好了？直接去[开工检查](/start/check/)，不用重复安装。

## 接下来会做什么

**案例一：一个个人主页。** 只用 HTML 和 CSS，重点练习需求分析、运行和具体反馈。

**案例二：给 Todo 加备注。** 先读懂已有项目，控制修改范围，再检查新旧功能。

两个案例都沿着五步走：**想清楚 → 定计划 → 生成并运行 → 发现问题并修改 → 检查并交付。**
