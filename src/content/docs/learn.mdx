## 选择适合你的起点

- **第一次接触开发工具**：从安装 VS Code 开始，按章节顺序阅读。
- **已经能运行项目**：从“发出第一个清楚的任务”开始。
- **想先看看完整过程**：直接进入案例，再回来看遇到的概念。

每页只围绕一个明确任务。工具差异集中在 Agent 章节，后续案例使用同一套协作方法。
