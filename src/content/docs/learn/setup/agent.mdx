## 编辑器、Agent 与模型

- **VS Code**：打开文件、阅读代码和使用终端的工作台。
- **编程 Agent**：在授权范围内阅读项目、修改文件、运行命令的工具。
- **模型**：Agent 用来理解需求、分析与生成内容的能力来源。

安装工具与连接模型是两个步骤。账号、额度、系统支持和连接方式可能不同，按你选择的工具完成配置。

默认使用 OpenCode 2 CLI 走完“安装 → 连接模型 → 只读任务”。在下方选择系统，逐步操作；已经有其他工具的同学直接切换工具查看差异。

| 工具        | 可从哪里开始                     | 官方资料                                                                                             |
| ----------- | -------------------------------- | ---------------------------------------------------------------------------------------------------- |

| Claude Code | 终端或 VS Code 扩展              | [快速开始](https://code.claude.com/docs/en/overview)                                                 |

Codex CLI 可以在本地目录中读写代码并运行命令；也可以在 VS Code 使用官方 IDE 扩展。安装与登录细节以 [OpenAI 官方文档](https://developers.openai.com/codex/cli) 为准。

## 第一次进入项目

打开项目目录后，先发一个只读任务：

```text title="第一条任务"
请先查看这个项目，说明：
1. 它使用什么技术，主要文件在哪里？
2. 如何安装依赖并在本地运行？
3. 目前有哪些需要我确认的前置条件？
先不要修改文件，也不要扩展功能。
```

检查 Agent 列出的路径是否来自当前项目，运行方式是否能在 README 或脚本中找到依据。确认后再开始修改。

## 确认操作范围

读取文件、修改文件和执行命令是不同的动作。看到权限请求时，先看目标文件、工作目录与命令用途。账号或密钥只在工具支持的连接界面配置，不放进项目代码。

[Pi 默认没有权限确认弹窗](https://pi.dev/#what-we-didnt-build)，可通过运行环境或扩展配置操作边界。“先读再改”是协作约定，使用前仍要了解当前工具的实际权限。
