## 先安装这些工具

| 工具    | 用途                                                 | 官方入口                                        |
| ------- | ---------------------------------------------------- | ----------------------------------------------- |
| Node.js | 运行 JavaScript 开发工具和案例二后端；npm 随安装提供 | [下载 LTS 版本](https://nodejs.org/en/download) |
| npm     | 根据项目的 package.json 安装依赖、运行脚本           | 随 Node.js 提供                                 |
| Git     | 查看代码差异，记录与恢复版本                         | [下载 Git](https://git-scm.com/downloads)       |

安装后重新打开终端，再检查命令是否能找到工具：

```sh title="在 VS Code 终端中运行"
node --version
npm --version
git --version
```

显示版本号说明命令可用。案例一只有 HTML 和 CSS，可以直接打开文件；需要本地服务时，使用已安装的 Python 3 运行 `python3 -m http.server 4322`，或 Windows 的 `py -m http.server 4322`。没有 Python 时可从 [Python 官网](https://www.python.org/downloads/) 安装。

## 遇到报错时，先查什么

| 现象                                   | 先检查                                           |
| -------------------------------------- | ------------------------------------------------ |
| command not found / 不是内部或外部命令 | 工具是否安装，终端是否在安装后重新打开           |
| 找不到 package.json                    | 终端是否进入了正确项目目录                       |
| 端口已被占用                           | 是否已经启动过同一个服务，或其他程序使用了该端口 |
| 页面打开但数据加载失败                 | 后端是否同时运行，终端有没有接口报错             |

把完整报错、执行的命令和当前目录一起提供给 Agent，比“跑不起来”更容易定位问题。
