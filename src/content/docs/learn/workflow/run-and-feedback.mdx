## 一条有用的反馈包含什么

```text title="针对具体问题反馈"
环境：375px 手机视口。
现象：页面出现横向滚动，项目卡片被截断。
预期：页面宽度适应屏幕，项目卡片在小屏显示为一列。
范围：只修改相关样式，保留文案、配色与邮件入口。
修改后请检查 375px 和 1280px，并说明改动。
```

不必先知道问题的技术原因。你也可以提供截图、复现步骤与预期效果，让 Agent 分析原因；能确定的事实比猜测更有用。

## 修改后，再检查一次

- 原来的问题是否解决？
- 桌面端或其他已有功能是否受影响？
- 修改是否保持在约定范围内？
- Agent 报告的检查是否实际执行，有什么输出？

全栈案例还要走完“输入 → 保存 → 重新读取”。只在输入框里看见文字，无法证明数据已经进入数据库。
