## 常见问题

<details>
  <summary>终端路径不以 my-homepage 结尾</summary>
  终端会沿用打开时的目录。确认 VS Code 已载入 my-homepage，关闭当前终端标签页，再新建终端。
</details>

<details>
  <summary>Agent 在错误的目录下启动</summary>
  切换工作区不会结束已经运行的进程。输入 exit 退出 Agent，核对路径后重新启动。
</details>

<details>
  <summary>首次提交提示缺少提交者身份</summary>
  在终端执行 git config --global user.name 与 git config --global user.email，写入提交时使用的名字和邮箱。
</details>
