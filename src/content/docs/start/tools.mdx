## 常见问题

<details>
  <summary>终端提示找不到命令</summary>
  关闭全部 VS Code 窗口，重新打开后再试。仍然失败时，检查安装目录是否已加入 PATH。
</details>

<details>
  <summary>Windows PowerShell 提示脚本运行受限</summary>
  本地执行策略阻止了脚本。在终端面板的下拉菜单中把默认终端切换为命令提示符，或改用 PowerShell 7。
</details>

<details>
  <summary>下载依赖或安装包时超时</summary>
  检查网络与代理设置，按控制台给出的错误码处理。不要用管理员权限运行来源不明的脚本。
</details>
