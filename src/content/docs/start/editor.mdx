VS Code 是编辑器：文件在哪里、代码改了什么、命令在哪输入，都可以在同一个窗口里看。

## 安装

1. 打开 [VS Code 官方下载页](https://code.visualstudio.com/download)。
2. 选择你的系统与芯片：Windows 通常是 x64；Mac 可在“关于本机”查看 Apple 芯片或 Intel。
3. 安装并启动。Windows 安装时可勾选添加到 PATH；安装后重开终端。
4. 可选：在扩展区搜索 **Chinese (Simplified) Language Pack**，确认发布者为 Microsoft。

不要从不明下载站安装。暂时不用装一大批插件。

## 认识三个区域和 Agent 入口

- **文件区**：左侧资源管理器，显示当前项目里的文件。
- **编辑区**：点击文件后，在中间查看和编辑，`Ctrl+S`（Mac `⌘S`）保存。
- **集成终端**：菜单“终端 → 新建终端”，用来输入命令。先看提示符的路径，确认当前目录。

Agent 可以在集成终端或自己的扩展面板中使用。点击区域看职责；这里是界面地图，不是远程 VS Code。此时不用创建项目，后面的开工检查会带你操作。

## 遇到问题

<details>
  <summary>code 命令找不到</summary>
  可以先用 VS Code 的“文件 → 打开文件夹”，不影响后续学习。Mac 可从命令面板搜索
  **Shell Command: Install 'code' command in PATH**。Windows
  可检查安装时是否添加到 PATH，再重开终端。
</details>

<details>
  <summary>打开了软件，却看不到项目文件</summary>
  启动编辑器不等于打开了项目。使用“File（文件）→ Open
  Folder（打开文件夹）”，不要只打开一个 HTML
  文件。下一节会带你创建并打开统一目录。
</details>

<details>
  <summary>找不到终端，或误把输出窗口当成终端</summary>
  输出窗口主要展示日志，不能代替命令行。使用“Terminal（终端）→ New
  Terminal（新建终端）”，看到路径和输入光标后再输入命令。
</details>

<details>
  <summary>中文说明和英文菜单对不上</summary>
  界面语言不影响功能。记住
  File（文件）、Explorer（资源管理器）、Terminal（终端）；也可从命令面板搜索操作名称，不必安装额外工作台插件。
</details>
