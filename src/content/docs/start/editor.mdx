## 打开项目与终端

<CardGrid>
  <Card title="打开工作区">
    菜单选择文件 → 打开文件夹，选中项目根目录。不要单独打开一个文件。
  </Card>
  <Card title="打开终端">
    按下 Ctrl 与反引号，或菜单选择终端 → 新建终端。macOS 使用 Control 与反引号。
  </Card>
</CardGrid>

安装完成后先打开一次，确认菜单能显示中文；语言包只影响菜单名称，不影响后续操作。

## 常见问题

<details>
  <summary>系统终端提示找不到 code 命令</summary>
  用菜单打开文件夹即可，不影响后续步骤。macOS 也可以在命令面板执行安装 Shell 路径的命令。
</details>

<details>
  <summary>左侧看不到文件列表</summary>
  当前窗口只打开了一个文件。使用文件 → 打开文件夹，选择项目根目录。
</details>

<details>
  <summary>找不到终端，或把输出面板当成终端</summary>
  输出面板只显示日志，不接受输入。打开终端 → 新建终端，出现路径前缀与输入光标后即可输入命令。
</details>

<details>
  <summary>菜单名称是英文</summary>
  在扩展市场安装 Chinese Language Pack，重启后菜单显示中文。
</details>
