## 常见问题

<details>
  <summary>进入交互界面后提示没有可用模型</summary>
  先执行 /connect 完成授权，再用 /models 选择该账号可用的模型。
</details>

<details>
  <summary>提示额度不足或没有访问权限</summary>
  到服务商控制台确认余额、计费状态与模型调用权限。
</details>

<details>
  <summary>提示认证失败或凭证无效</summary>
  API Key 是提供商发给你的访问凭证。检查复制时是否带入空格；凭证失效后重新生成，并在 /connect 中重新填入。
</details>

<details>
  <summary>网络连接超时或请求无响应</summary>
  检查本地代理设置，确认能够稳定访问服务商的 API 地址。
</details>
